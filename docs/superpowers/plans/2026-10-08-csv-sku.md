# Peças por SKU — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produtos identificados por SKU, agrupados em peças (SKU_PAI) com os tamanhos lá dentro no Vender e em Produtos, CSV só no formato novo, e promoções que contam o produto inteiro.

**Architecture:** O modelo `Product` ganha `sku`, `sku_pai`, `cor`; uma função pura `groupPieces` agrupa artigos em peças para a UI; `priceCart` substitui o cálculo linha a linha no carrinho e na venda; `savePiece` grava uma peça com todos os tamanhos numa só transação.

**Tech Stack:** React 19 + TypeScript (strict), Vite, Vitest, zustand, IndexedDB (via `src/db/database.ts`).

**Spec:** `docs/superpowers/specs/2026-10-08-csv-sku-design.md` · Mockup: `docs/superpowers/mockups/csv-sku.html`

## Global Constraints

- **Não fazer commits** (pedido do utilizador). Os passos "Commit" deste plano são substituídos por: `npm run typecheck && npm test` verdes.
- Textos da interface em português de Portugal, no tom atual da app.
- Código e comentários seguem o estilo atual (comentários curtos em português, imports com extensão `.ts`/`.tsx`).
- Cálculos de dinheiro em cêntimos (`toCents`/`fromCents`); a soma das linhas bate ao cêntimo.
- Ícone de lixeira (`TrashIcon`) em todas as ações de apagar, exceto nos botões das janelas de confirmação.
- Áreas de toque dos botões de tamanho ≥ 44px de altura no telemóvel.
- Sem migração de dados nem suporte ao formato antigo de CSV.

## Review Focus

- Tamanhos escritos de formas diferentes (`s`, ` S `, `xxl`, `2xl`) — devem ordenar e gerar SKU como `S`, `2XL`. Teste em Task 2.
- `SKU_FILHO` repetido entre linhas do CSV — fica o primeiro, os outros vão para os erros. Teste em Task 3.
- Remover um tamanho de uma peça que está no carrinho — o artigo sai do carrinho (prune já existente), sem erro na venda. Teste em Task 5.
- Mesmo nome de produto com promoções diferentes por cor — só se juntam as linhas com a mesma promoção. Teste em Task 4.
- Peça com um tamanho "sem limite" — total da peça mostra ∞ e não conta para "esgotado". Teste em Task 2.

### Task 2: Peças — agrupamento, tamanhos e SKUs gerados

**Files:**
- Create: `src/lib/pieces.ts`
- Test: `tests/pieces.test.ts`

**Interfaces:**
- Produces:
  - `normCor(raw: unknown): string` — `''` para `—`, `-`, vazio; senão o texto aparado.
  - `normTamanho(raw: unknown): string` — `''` para `Único`/`Unico`/`U`/`—`/`-`/vazio (sem distinguir maiúsculas); senão aparado e em maiúsculas; `XXL`→`2XL`, `XXXL`→`3XL`.
  - `compareSizes(a: string, b: string): number` — ordem `XXS, XS, S, M, L, XL, 2XL, 3XL, 4XL, 5XL`; depois números crescentes; depois alfabético; `''` primeiro.
  - `interface Piece { sku_pai: string; nome: string; cor: string; variants: Product[]; stockTotal: number | null; precoMin: number; precoMax: number; categorias: string[] }`
  - `groupPieces(products: Product[]): Piece[]` — por `sku_pai`; variantes ordenadas por `compareSizes`; peças por nome e depois cor (`localeCompare` pt, base); `stockTotal` = soma de `qtd`, `null` se algum `sem_limite`; `nome`/`cor` da 1.ª variante.
  - `isSingleSize(piece: Piece): boolean` — 1 variante com `tamanho === ''`.
  - `skuPai(nome: string, cor: string): string` — 3 letras (sem acentos, maiúsculas, só A-Z0-9) de cada uma das 2 primeiras palavras do nome + 2 letras da cor; partes vazias omitidas; unidas por `-`.
  - `skuFilho(pai: string, tamanho: string): string` — `PAI-TAMANHO`; tamanho único → `pai`.

**Interfaces:**

  - Olga 2XL ×1 + Olga 3XL ×1, 15 €, `LEVE_2_PAGUE_1` → totais `[15, 0]`, descontos `[0, 15]` (empate de preço: a última linha fica grátis).
  - Amílcar Verde S ×1 + Amílcar Preta M ×1 (mesmo nome) em 2 por 1 → soma 15, desconto total 15.
  - Preços 12 e 15 no mesmo grupo 2 por 1 → grátis a de 12: totais `[0, 15]` para `[12, 15]`.
  - `PACK_3` com `preco_especial` 10, preços `[5,5,5,4]` ×1 cada → pack com as 3 de 5 (10 €) + a de 4 normal: soma 14.
  - Mesmo nome, uma linha `LEVE_2_PAGUE_1` e outra sem promoção → não se juntam (cada uma ao preço normal).
  - Sem promoção com `preco_especial` 9 → `total = 9 × qtd`.
  - Nome com acentos/maiúsculas diferentes (`'Camiseta Olga'` vs `'camiseta olga'`) → mesmo grupo.
  - Para todos: `Σ total + Σ desconto === Σ bruto` ao cêntimo.
